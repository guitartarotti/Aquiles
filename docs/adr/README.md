# Architecture Decision Records

Este diretório registra decisões arquiteturais relevantes do Aquiles. Cada ADR é
imutável depois de aceito: mudanças de direção devem criar um novo documento que
substitua explicitamente o anterior.

## Status

- **Proposto**: em discussão e ainda não aplicado como padrão.
- **Aceito**: decisão vigente e protegida por implementação ou testes.
- **Substituído**: preservado como histórico, com referência ao ADR sucessor.
- **Rejeitado**: alternativa avaliada e não adotada.
